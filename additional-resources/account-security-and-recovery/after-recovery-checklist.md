# After-Recovery Security Checklist

**You've regained access to your account. What now?**

Getting back into an account is a great start, but it does not always mean the attacker has lost every way of accessing it.

Use this checklist after recovering an email, social media, messaging, shopping or other online account.

## 1. Secure the password

- [ ] Change the password.
- [ ] Make sure it is unique to this account.
- [ ] Change the password anywhere else it was reused.
- [ ] Store the new password securely in a password manager.

## 2. Review sign-in access

- [ ] Review recent sign-in activity.
- [ ] Remove unfamiliar devices.
- [ ] Sign out of sessions you do not recognise.
- [ ] Check trusted devices.
- [ ] Review active sessions again after changing the password.

## 3. Check recovery options

- [ ] Confirm the recovery email address is yours.
- [ ] Confirm the recovery phone number is yours.
- [ ] Remove unfamiliar recovery methods.
- [ ] Review passkeys and security keys.
- [ ] Review authenticator applications.
- [ ] Save recovery codes somewhere safe.

## 4. Enable multi-factor authentication

- [ ] Enable multi-factor authentication.
- [ ] Prefer a passkey, security key or authenticator app where supported.
- [ ] Avoid relying only on SMS where stronger options are available.
- [ ] Never approve a sign-in request you did not initiate.
- [ ] Never share verification codes.

## 5. Check email settings

If the account is an email account:

- [ ] Check forwarding rules.
- [ ] Check inbox filters.
- [ ] Check automatic replies.
- [ ] Check delegated mailbox access.
- [ ] Review sent messages.
- [ ] Review deleted messages.
- [ ] Check for unfamiliar connected applications.

## 6. Check connected services

- [ ] Review third-party applications.
- [ ] Remove unfamiliar integrations.
- [ ] Review linked social media accounts.
- [ ] Check cloud storage sharing.
- [ ] Check payment methods.
- [ ] Review recent purchases and transactions.

## 7. Check for misuse

- [ ] Review messages you did not send.
- [ ] Review posts and comments.
- [ ] Check for suspicious changes to your profile.
- [ ] Check for unfamiliar contacts or friends.
- [ ] Warn people who received suspicious messages.
- [ ] Report fraudulent content.

## 8. Secure other accounts

- [ ] Secure your primary email account.
- [ ] Change reused passwords.
- [ ] Review banking and payment accounts.
- [ ] Review social media accounts.
- [ ] Review government accounts.
- [ ] Review shopping and subscription accounts.

## 9. Secure your devices

- [ ] Install available operating system updates.
- [ ] Update your browser.
- [ ] Update applications.
- [ ] Run a security scan if malware is suspected.
- [ ] Remove unfamiliar applications.
- [ ] Review browser extensions.
- [ ] Seek technical assistance if the device may still be compromised.

## 10. Monitor your accounts

For the next few weeks:

- [ ] Watch for unexpected password reset emails.
- [ ] Check account activity.
- [ ] Watch for unusual purchases or transactions.
- [ ] Look for unfamiliar sign-in notifications.
- [ ] Be alert to messages from people claiming they can recover your account.
- [ ] Keep incident records and reference numbers.

## 11. Report and seek support

In Australia:

- [ ] Report cybercrime through [ReportCyber](https://www.cyber.gov.au/report).
- [ ] Report scams through [Scamwatch](https://www.scamwatch.gov.au/).
- [ ] Contact [IDCARE](https://www.idcare.org/) if identity information was exposed.
- [ ] Contact your bank if financial information or money was affected.
- [ ] Contact your workplace IT or security team if a work account or device was involved.

## Final check

Before considering the incident resolved, ask yourself:

- Can I access the account?
- Do I control all recovery methods?
- Have unfamiliar sessions been removed?
- Have I checked for hidden forwarding or connected access?
- Have I secured other accounts that may share the same password?
- Have I checked whether money or identity information was exposed?

If you cannot confidently answer these questions, get help before assuming the account is safe.
