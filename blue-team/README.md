## Core Concepts

- **SIEM:** Centralised collection, correlation and analysis of security events.
- **EDR:** Endpoint telemetry, detection, investigation and response.
- **Telemetry:** Data generated by systems, applications, identities and network infrastructure.
- **Detection:** Logic used to identify suspicious or malicious activity.
- **Alert triage:** Determining whether an alert represents genuine security risk.
- **Correlation:** Connecting related events across systems and time.
- **Containment:** Limiting the impact and spread of a security incident.

## Operational Principles

1. Establish visibility before developing detections.
2. Understand normal activity before defining suspicious behaviour.
3. Correlate multiple data sources rather than relying on isolated events.
4. Validate alerts using supporting evidence.
5. Preserve investigation context and timestamps.
6. Avoid destructive response actions without appropriate authorisation.
7. Continuously tune detections based on investigation outcomes.
