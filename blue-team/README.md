# Blue Team

Defensive cybersecurity practices, monitoring, detection, investigation and response.

This section provides practical guidance for security professionals responsible for protecting systems, identifying malicious activity, investigating incidents and improving an organisation's security posture.

This section is intended for:

- SOC analysts and security operations teams
- Incident responders
- Threat hunters
- Security engineers
- Systems and network administrators
- Digital forensic practitioners
- IT professionals developing defensive security skills
