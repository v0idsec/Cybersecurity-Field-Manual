# Phishing Templates

This directory contains reusable templates for defensive phishing investigation, reporting and security awareness activities.

## Templates

| File | Purpose |
|---|---|
| [Phishing Report](phishing-report-template.md) | Record a suspicious message reported by a user |
| [Phishing Triage](phishing-triage-template.md) | Perform initial assessment and prioritisation |
| [Phishing Incident Report](phishing-incident-report-template.md) | Document a confirmed phishing incident |
| [Phishing Awareness Exercise](phishing-awareness-exercise-template.md) | Plan and document an awareness exercise |
| [Phishing Simulation Plan](phishing-simulation-plan-template.md) | Define an authorised phishing simulation |
| [Suspicious Email Analysis](suspicious-email-analysis-template.md) | Record detailed technical email analysis |
| [User Notification](user-notification-template.md) | Communicate phishing incidents and required actions |

## Usage

- Copy the relevant template into the organisation's case management or documentation system.
- Replace placeholders with verified information.
- Remove sections that are not applicable.
- Protect sensitive information.
- Follow internal retention and evidence-handling policies.

## Simulation Requirements

Phishing simulations require:
- Written approval
- Defined scope
- Agreed dates
- Named stakeholders
- Privacy safeguards
- No collection of real passwords
- A safe landing or educational page
- A clear reporting and support process
- Defined stop conditions
- Post-exercise review

Simulation results should be used to improve security awareness and controls, not to shame individual employees.
