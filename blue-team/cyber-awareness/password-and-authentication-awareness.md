# Password and Authentication Awareness

## Overview

Passwords and authentication factors protect access to organisational systems, services and information.

Poor authentication practices can lead to account compromise, data exposure and unauthorised access.

Employees should understand how to protect credentials and recognise suspicious authentication activity.

## Password Security

Recommended practices:

- Use unique passwords for different services.
- Use long passwords or passphrases.
- Use an organisation-approved password manager.
- Never share passwords.
- Never send passwords through ordinary email or messaging.
- Avoid predictable personal information.
- Change passwords when compromise is suspected or required by policy.
- Follow organisational password requirements.

Avoid arbitrary complexity rules that encourage predictable substitutions and frequent unnecessary password changes.

## Password Managers

Approved password managers can help employees:

- Generate strong passwords.
- Store unique credentials.
- Reduce password reuse.
- Identify reused or weak passwords.
- Share approved credentials securely where supported.

Employees should only use organisation-approved products for business credentials.

## Multi-Factor Authentication

MFA requires more than one authentication factor.

Common categories:

| Factor | Example |
|---|---|
| Something you know | Password or PIN |
| Something you have | Security key or registered device |
| Something you are | Fingerprint or facial recognition |

MFA can reduce the impact of password compromise, but not every MFA method offers the same level of protection.

## MFA Fatigue

Attackers may repeatedly trigger authentication requests in an attempt to persuade an employee to approve one.

Employees should:

- Reject unexpected authentication requests.
- Never approve a request they did not initiate.
- Report repeated or unusual prompts.
- Contact IT through an approved channel.
- Follow the organisation's account-compromise procedure.

## Phishing-Resistant Authentication

Where supported, prefer phishing-resistant authentication such as FIDO2 security keys or passkeys.

These methods can provide stronger protection against credential phishing because authentication is cryptographically bound to the legitimate service.

## Authentication Codes

Never disclose:

- One-time passwords.
- MFA approval codes.
- Recovery codes.
- Password reset links.
- Security key PINs.

Legitimate support personnel should not need an employee to disclose an authentication code.

## Account Recovery

Employees should:

- Use approved account recovery procedures.
- Keep recovery information current where permitted.
- Report unexpected password reset messages.
- Avoid recovery through unverified support contacts.
- Secure recovery codes according to policy.

## Privileged Accounts

Administrators and other privileged users should:

- Use dedicated administrative accounts.
- Avoid routine browsing with privileged accounts.
- Use approved privileged access management tools.
- Protect administrative authentication factors.
- Follow just-in-time access requirements where implemented.
- Report suspected privileged account compromise immediately.

## Common Warning Signs

- Unexpected password reset notifications.
- MFA prompts that were not initiated.
- Login alerts from unfamiliar locations.
- Repeated account lockouts.
- Unexpected changes to recovery information.
- Requests to disclose authentication codes.
- Unexpected requests to install remote access software.

## If Credentials Are Exposed

1. Report the event immediately.
2. Follow the organisation's account compromise process.
3. Change the affected password using a trusted device and approved method.
4. Revoke active sessions where directed.
5. Review MFA methods and recovery information.
6. Report any suspicious activity.
7. Avoid reusing the exposed password elsewhere.

Security teams should determine whether additional containment is required.

## Key Takeaways

Authentication security is not just about creating a strong password.

Protect credentials, use approved MFA, reject unexpected prompts and report suspicious account activity.
