# Security Awareness Fundamentals

## Overview

Security awareness is the process of helping people recognise security risks and make safer decisions when using organisational systems, information and technology.

Technology alone cannot prevent every incident. Employees interact with email, applications, devices, customers, suppliers and sensitive information every day.

A well-designed awareness programme helps reduce preventable risk while making it easier for employees to identify and report suspicious activity.

## Objectives

A security awareness programme should help employees:

- Recognise common cyber threats.
- Understand their security responsibilities.
- Protect credentials and authentication factors.
- Identify suspicious emails, messages and websites.
- Handle organisational information appropriately.
- Report suspected incidents quickly.
- Understand relevant policies and procedures.
- Make safer decisions when working remotely.

## Common Human-Related Security Risks

| Risk | Example |
|---|---|
| Phishing | Employee follows a malicious email link |
| Credential exposure | Password entered into a fake login page |
| Social engineering | Caller impersonates an IT administrator |
| Data exposure | Sensitive file shared with an unauthorised recipient |
| Unsafe browsing | Employee downloads an untrusted application |
| Physical security | Unauthorised visitor follows staff into a restricted area |
| Device compromise | Employee installs unapproved software |
| Business email compromise | Employee acts on fraudulent payment instructions |

## The Human Element

Employees should not be treated as the weakest link.

Security failures can result from:

- Confusing processes.
- Excessive workloads.
- Poorly designed applications.
- Unclear policies.
- Insufficient training.
- Inadequate technical controls.
- Deliberate deception by attackers.

Awareness programmes should address both individual behaviour and organisational conditions.

## Core Awareness Topics

### Identity and Authentication

- Use unique passwords.
- Use an approved password manager.
- Enable MFA where available.
- Never share authentication codes.
- Report unexpected MFA prompts.
- Use phishing-resistant authentication where supported.

### Email and Messaging

- Check unexpected requests carefully.
- Verify unusual payment or account-change requests.
- Treat unexpected attachments cautiously.
- Report suspicious messages.
- Avoid entering credentials through unsolicited links.

### Data Protection

- Use approved storage locations.
- Check recipients before sending sensitive information.
- Apply appropriate sharing permissions.
- Avoid transferring organisational data to personal accounts.
- Report accidental disclosure immediately.

### Device Security

- Lock unattended devices.
- Install approved updates.
- Avoid untrusted software.
- Report lost or stolen devices.
- Do not bypass security controls.

### Physical Security

- Wear required identification.
- Challenge or report suspicious access appropriately.
- Do not allow unauthorised tailgating.
- Secure printed documents.
- Protect unattended workspaces.

## Awareness Versus Training

**Awareness** builds recognition and understanding.

**Training** develops the knowledge and practical skills required to perform specific tasks.

Examples:

| Awareness | Training |
|---|---|
| Recognising phishing | Analysing suspicious email headers |
| Understanding MFA | Configuring an authentication application |
| Knowing data classification exists | Applying classification labels |
| Knowing how to report incidents | Performing an incident escalation |
| Understanding secure development | Performing secure code reviews |

Both are necessary.

## Designing Effective Awareness

Effective awareness content should be:

- Relevant to the audience.
- Written in plain language.
- Short enough to retain attention.
- Supported by practical examples.
- Available in accessible formats.
- Reinforced over time.
- Measured against defined outcomes.

Avoid relying entirely on annual compliance presentations.

## Common Programme Failures

| Failure | Improvement |
|---|---|
| One annual training session | Use ongoing reinforcement |
| Generic content | Tailor examples to roles |
| Shaming employees | Encourage reporting and learning |
| Measuring only click rates | Measure reporting and behaviour |
| Excessive technical language | Use plain language |
| No management involvement | Establish leadership support |
| No follow-up | Review outcomes and improve content |

## Key Takeaways

Security awareness is an ongoing organisational capability, not a once-a-year compliance exercise.

A successful programme makes secure behaviour easier, encourages early reporting and helps employees understand how their actions contribute to organisational security.
