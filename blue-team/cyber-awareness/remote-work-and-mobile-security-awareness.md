# Remote Work and Mobile Security Awareness

## Overview

Remote working introduces additional security considerations involving home networks, mobile devices, public locations and remote access services.

Employees should understand how to protect organisational information outside traditional office environments.

## Remote Working Responsibilities

Employees should:

- Use approved devices.
- Follow remote access requirements.
- Protect devices from unauthorised access.
- Keep software updated.
- Use approved communication and storage services.
- Protect confidential conversations.
- Report lost or stolen equipment.
- Follow organisational security policies.

## Home Network Security

Recommended practices:

- Change default router administrator credentials.
- Use modern Wi-Fi security such as WPA2-AES or WPA3.
- Keep router firmware updated.
- Disable unnecessary remote administration.
- Use a strong Wi-Fi password.
- Avoid exposing internal services directly to the internet.
- Separate guest devices where supported.

Employees should not make changes that conflict with organisational or ISP requirements.

## Public Networks

When using public Wi-Fi:

- Verify the network name with the venue.
- Avoid unknown or suspicious access points.
- Use approved VPN services where required.
- Avoid accessing sensitive information on untrusted devices.
- Disable unnecessary file sharing.
- Do not ignore browser certificate warnings.

## Mobile Device Security

Employees should:

- Use device screen locks.
- Enable supported device encryption.
- Install updates promptly.
- Use approved applications.
- Avoid jailbreaking or rooting work devices.
- Protect devices from theft.
- Report loss or suspected compromise.
- Follow mobile device management requirements.

## Application Permissions

Review application permissions carefully.

Be cautious of applications requesting unnecessary access to:

- Contacts.
- Microphone.
- Camera.
- Location.
- Files.
- Accessibility services.
- Notifications.

Only install applications approved for organisational use.

## Device Loss or Theft

If a work device is lost or stolen:

1. Report it immediately.
2. Provide the last known location and circumstances where appropriate.
3. Do not attempt to recover it if doing so creates a safety risk.
4. Follow instructions from IT or security.
5. Allow authorised teams to perform remote locking or wiping where supported.
6. Report any associated account or data exposure concerns.

## Working in Public

Protect information when working in shared environments.

Consider:

- Screen visibility.
- Shoulder surfing.
- Private conversations.
- Printed documents.
- Unattended devices.
- Charging stations and unknown accessories.
- Nearby individuals overhearing sensitive calls.

Use privacy screens where appropriate.

## Remote Access

Employees should:

- Use approved remote access services.
- Protect authentication factors.
- Avoid sharing remote access sessions.
- Report unexpected login prompts.
- Disconnect when finished where required.
- Never install remote access software at the request of an unverified caller.

## Family and Shared Devices

Avoid using personal or shared family devices to access organisational systems unless explicitly approved.

Do not allow other household members to use an authenticated work session.

## Key Takeaways

Remote work requires the same security discipline as office work, with additional attention to physical surroundings, networks and device protection.
