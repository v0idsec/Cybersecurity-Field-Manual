# Cyber Awareness Templates

Reusable templates for planning, delivering and reviewing security awareness activities.

## Available Templates

| Template | Purpose |
|---|---|
| [Awareness Campaign Plan](awareness-campaign-plan-template.md) | Plan an awareness campaign |
| [Security Training Record](security-training-record-template.md) | Record training delivery and completion |
| [Security Awareness Incident Communication](security-awareness-incident-communication-template.md) | Communicate security incidents to employees |
| [Awareness Programme Review](awareness-programme-review-template.md) | Review programme effectiveness |

## Usage

- Copy the relevant template.
- Replace placeholder text.
- Tailor the document to the organisation.
- Obtain required approvals.
- Store completed records in an approved location.
- Apply relevant privacy and retention requirements.

These templates are starting points and should be adapted to organisational policy.
