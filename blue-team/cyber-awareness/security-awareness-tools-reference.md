# Security Awareness Tools Reference

## Overview

This document provides a reference to platforms and tools that can support security awareness, training delivery, phishing reporting and programme measurement.

Tool suitability depends on organisational size, licensing, privacy requirements and existing technology.

## Measurement and Reporting

Useful data sources include:

- Learning management system reports.
- Email security reporting.
- SIEM dashboards.
- Incident management systems.
- Help desk tickets.
- Employee feedback surveys.
- Approved simulation platforms.

## Tool Selection Considerations

Evaluate:

- Data residency.
- Privacy and employee monitoring implications.
- Integration with existing identity systems.
- Reporting capabilities.
- Accessibility.
- Licensing.
- Content quality.
- Automation.
- Retention and deletion controls.
- Vendor security and compliance.

## Operational Considerations

Before deploying awareness tools:

1. Obtain organisational approval.
2. Define programme ownership.
3. Review privacy and employment requirements.
4. Establish data retention rules.
5. Configure role-based access.
6. Test integrations.
7. Document reporting procedures.
8. Review vendor security.
9. Monitor platform usage.
10. Reassess suitability periodically.

## Important Note

A tool does not replace an awareness programme.

Training platforms should support clear objectives, practical education, constructive feedback and measurable improvement.
