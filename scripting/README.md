# Scripting Templates

A collection of reusable scripting templates for common cybersecurity and IT tasks.

Scripts are divided into two categories:

- **Red Team:** Authorised reconnaissance, enumeration and information gathering.
- **Blue Team:** Defensive investigation, system auditing, log analysis and monitoring.

## Structure

| Directory | Description |
|---|---|
| [Red Team](red-team/README.md) | Scripts for authorised security assessments |
| [Blue Team](blue-team/README.md) | Scripts for defensive security and investigation |

## Languages

The collection primarily uses:

- PowerShell (`.ps1`)
- Python (`.py`)

## Usage

1. Open the relevant script.
2. Review the comments and configuration variables.
3. Update placeholders for your environment.
4. Check dependencies and permissions.
5. Test in a controlled environment.
6. Review the output.

## Important

These scripts are templates, not production-ready security products.

Always review scripts before execution. Test them in a safe environment and obtain appropriate authorisation before performing network discovery or security assessments.

Do not run scripts against systems or networks without permission.
