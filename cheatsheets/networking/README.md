## Common tools

- `ping`
- `traceroute` / `tracert`
- `ip`
- `ipconfig`
- `ss`
- `netstat`
- `nslookup`
- `dig`
- `curl`
- `tcpdump`
- Wireshark
- Nmap
- `arp`
- `route`
- `mtr`

## Usage

Commands and techniques should only be used against systems and networks you own or are authorised to assess.

Some commands require administrator or root privileges.
