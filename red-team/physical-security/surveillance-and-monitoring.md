# Surveillance and Monitoring

A reference for assessing CCTV, intrusion detection, alarm systems and the monitoring processes used to identify physical security incidents.

Security technology is only effective when it is appropriately configured, maintained, monitored and supported by clear response procedures.

## Assessment objectives

- Review surveillance coverage.
- Assess camera suitability and recording quality.
- Review recording retention.
- Evaluate intrusion detection.
- Assess alarm notification and escalation.
- Review security monitoring responsibilities.
- Evaluate incident investigation processes.

## 1. CCTV architecture

Identify the components of the surveillance environment.

Examples:

- Fixed cameras.
- Pan-tilt-zoom cameras.
- Network video recorders.
- Digital video recorders.
- Video management systems.
- Monitoring workstations.
- Remote viewing platforms.
- Storage infrastructure.

Document relevant systems and their responsibilities.

## 2. Camera coverage

Review approved camera coverage diagrams and available footage.

Consider whether cameras appropriately cover:

- Main entrances.
- Reception.
- Restricted-area entrances.
- Loading docks.
- Vehicle access points.
- Car parks.
- External boundaries.
- Server rooms.
- Critical infrastructure areas.

Identify coverage limitations and operational constraints.

Do not attempt to evade cameras or test concealment techniques.

## 3. Image quality

Assess whether footage is suitable for its intended purpose.

Consider:

- Resolution.
- Frame rate.
- Lighting.
- Image compression.
- Camera positioning.
- Field of view.
- Environmental conditions.
- Time synchronisation.

A camera may technically be operational while producing footage that is unsuitable for investigation.

## 4. Recording and retention

Review:

- Recording schedules.
- Storage capacity.
- Retention periods.
- Video export procedures.
- Access permissions.
- Evidence preservation.
- Backup arrangements.
- Deletion policies.

Confirm that retention meets organisational and regulatory requirements.

## 5. CCTV system security

Network-connected cameras and recording systems should be treated as IT assets.

Review:

- Default credential removal.
- Unique administrator accounts.
- Strong authentication.
- Network segmentation.
- Remote access controls.
- Firmware maintenance.
- Logging.
- Vendor access.
- Secure configuration backups.
- Exposure to public networks.

Consider whether cameras are isolated from unnecessary corporate and production systems.

## 6. Intrusion detection

Identify the intrusion detection mechanisms used by the facility.

Examples:

- Door contacts.
- Window contacts.
- Motion detectors.
- Glass-break sensors.
- Perimeter sensors.
- Vibration sensors.
- Restricted-area alarms.

Review:

- Sensor coverage.
- Configuration management.
- Maintenance.
- Alert handling.
- False alarm management.
- Monitoring responsibilities.

## 7. Alarm management

Assess how alarms are received and handled.

Review:

- Alarm classification.
- Notification procedures.
- Escalation paths.
- Security personnel responsibilities.
- External monitoring arrangements.
- Response time objectives.
- Incident records.
- False alarm procedures.

## 8. Security operations

Evaluate the people and processes responsible for monitoring physical security.

Consider:

- Monitoring coverage.
- Shift handovers.
- Staff training.
- Incident escalation.
- Alarm acknowledgement.
- Response procedures.
- Investigation processes.
- Documentation.

Technology should not be treated as a substitute for operational procedures.

## 9. Integration with other systems

Review integrations with:

- Access-control systems.
- Building management systems.
- Intrusion detection.
- Fire and life-safety systems.
- Security operations platforms.
- SIEM solutions.

Confirm that relevant events can be correlated and investigated.

## 10. Controlled validation

Use approved test events and designated personnel.

Examples:

- Confirming that an approved test alarm is received.
- Verifying that access events appear in logs.
- Reviewing CCTV footage for a designated test period.
- Confirming time synchronisation.
- Validating recording retention.
- Confirming incident escalation procedures.

Do not disable cameras, suppress alarms or interfere with monitoring during live operations.

## Common findings

| Finding | Potential impact |
|---|---|
| Inadequate camera coverage | Reduced incident visibility |
| Poor image quality | Limited investigative value |
| Insufficient retention | Evidence unavailable when required |
| Unsecured camera administration | Unauthorised surveillance access |
| Unmonitored alarm events | Delayed incident response |
| Inaccurate timestamps | Difficult event correlation |
| Inadequate incident procedures | Inconsistent response |

## Remediation

- Review camera placement and coverage.
- Improve lighting and image quality.
- Establish retention requirements.
- Secure camera administration.
- Segment surveillance networks.
- Maintain firmware.
- Test alarm notification.
- Establish monitoring responsibilities.
- Document incident response procedures.
- Conduct regular system reviews.
