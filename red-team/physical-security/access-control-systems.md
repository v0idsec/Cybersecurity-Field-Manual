# Access Control Systems

A reference for assessing physical access-control systems, including employee credentials, visitor management, electronic readers, permissions and access administration.

Physical access control determines who can enter a facility, when they can enter and which areas they are permitted to access.

## Assessment objectives

- Review access-control architecture.
- Assess credential management.
- Evaluate access permissions.
- Review visitor and contractor processes.
- Assess lost and stolen credential handling.
- Review access logging and monitoring.
- Evaluate account lifecycle management.
- Identify excessive or inappropriate access.

## 1. Access-control architecture

Identify the components involved in granting and managing physical access.

Common components include:

- Access cards and badges.
- Proximity credentials.
- Smart cards.
- PIN-based systems.
- Biometric readers.
- Electronic door controllers.
- Access-control management software.
- Central identity systems.
- Visitor management platforms.
- Security monitoring systems.

Understand which systems are centrally managed and which operate independently.

## 2. Credential management

Review how physical credentials are issued, stored, maintained and revoked.

Consider:

- Employee badge issuance.
- Contractor credentials.
- Temporary visitor badges.
- Lost credential procedures.
- Stolen credential procedures.
- Replacement credentials.
- Credential expiry.
- Credential revocation.
- Unused credentials.
- Credential inventory.

Assess whether credentials are uniquely assigned and traceable to an authorised individual.

## 3. Access permissions

Evaluate how access permissions are assigned.

Review:

- Role-based access.
- Department-based access.
- Location-based access.
- Restricted-area permissions.
- Temporary access.
- After-hours permissions.
- Privileged access.
- Emergency access.

Access should follow least-privilege principles.

Personnel should only receive access required to perform their responsibilities.

## 4. Joiner, mover and leaver processes

Review the lifecycle of employee access.

### Joiners

- Is access formally approved?
- Are credentials uniquely assigned?
- Are permissions based on role?
- Is access limited to required locations?

### Movers

- Are old permissions reviewed?
- Are new permissions approved?
- Are unnecessary privileges removed?
- Are access changes recorded?

### Leavers

- Are credentials recovered?
- Is electronic access revoked promptly?
- Are lost credentials disabled?
- Are shared access arrangements reviewed?
- Are third-party accounts and permissions addressed?

## 5. Visitor management

Review how visitors are registered and supervised.

Consider:

- Visitor identity verification.
- Host approval.
- Visitor registration.
- Temporary badges.
- Visitor access restrictions.
- Escort requirements.
- Visitor departure procedures.
- Visitor record retention.

Assess whether visitors can be distinguished from employees and contractors.

## 6. Contractor access

Contractors may require temporary or recurring access.

Review:

- Contractor approval.
- Identity verification.
- Engagement dates.
- Access scope.
- Escort requirements.
- After-hours permissions.
- Credential expiry.
- Access revocation.

Consider how subcontractors are managed.

## 7. Authentication and identification

Where applicable, review the authentication mechanisms used by access-control systems.

Examples:

- Card-only access.
- PIN-only access.
- Card and PIN.
- Biometric authentication.
- Multi-factor physical access arrangements.

Assess whether the authentication method is appropriate for the sensitivity of the area.

## 8. Door monitoring and access events

Review whether access-control systems record relevant events.

Examples:

- Successful entry.
- Denied entry.
- Credential expiry.
- Door held open.
- Door forced open.
- Controller fault.
- Reader failure.
- Access permission changes.

Evaluate:

- Event retention.
- Timestamp accuracy.
- Log integrity.
- Monitoring responsibilities.
- Alert thresholds.
- Investigation procedures.

## 9. System administration

Review the security of access-control administration.

Consider:

- Administrator accounts.
- Role separation.
- Authentication requirements.
- Privileged account reviews.
- Change management.
- Configuration backups.
- Vendor access.
- Remote administration.
- Audit logging.
- Software maintenance.

Access-control management platforms should be treated as security-sensitive systems.

## 10. System integration

Assess integrations with:

- Human resources systems.
- Identity providers.
- Visitor management platforms.
- CCTV.
- Intrusion detection.
- Building management systems.
- Security information and event management platforms.

Review whether integrations are authenticated, monitored and maintained.

## 11. Controlled validation

Use designated test credentials and approved test areas.

Potential validation activities:

- Confirming that expired credentials are rejected.
- Confirming that test users cannot access unauthorised areas.
- Confirming that revoked credentials no longer work.
- Reviewing whether access events are logged.
- Verifying that temporary credentials expire as expected.
- Confirming that approved alerts are generated.

Do not test using another person's credential or attempt to access areas outside the agreed scope.

## Common findings

| Finding | Potential impact |
|---|---|
| Delayed credential revocation | Former personnel retain access |
| Excessive access permissions | Unnecessary exposure of restricted areas |
| Shared credentials | Reduced accountability |
| Inadequate visitor records | Limited incident traceability |
| Unmonitored access events | Delayed detection |
| Weak administrator controls | Unauthorised access-control changes |
| Unmanaged contractor access | Persistent third-party access |

## Remediation

- Centralise credential management where appropriate.
- Implement documented approval workflows.
- Conduct periodic access reviews.
- Revoke credentials promptly.
- Enforce unique credential assignment.
- Review privileged administration.
- Monitor access events.
- Establish retention requirements.
- Audit third-party access.
- Test joiner, mover and leaver processes regularly.
